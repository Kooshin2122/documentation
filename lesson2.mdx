Casharkan waxaad ku baran doontaa erayada aasaasiga ah ee Forex iyo sida **currency pairs** loo fahmo. Erayadan waxaad si joogto ah ugu arki doontaa charts, platforms, iyo casharrada xiga.

## Erayada muhiimka ah

<Tip>
  Liquidity sare waxay inta badan keentaa **spread cidhiidhi ah**. Volatility sare waxay kordhin kartaa fursadaha,
  laakiin sidoo kale khatarta.
</Tip>

## Tusaale: Bid, Ask, iyo pip

Haddii **EUR/USD** uu yahay sidan:

|            | Qiimaha |
| ---------- | ------- |
| **Bid**    | 1.1000  |
| **Ask**    | 1.1002  |
| **Spread** | 2 pips  |

Haddii qiimuhu ka dhaqaaqo **1.1000** una gudbo **1.1001**, taasi waa **1 pip**. Inta badan pairs-ka (aan ahayn JPY) 1 pip waa isbeddelka **0.0001**.

## Currency pairs

Forex laguma iibsado currency keliya. Mar walba waxaad iibsanaysaa mid, waxaadna iibinaysaa mid kale.

**EUR/USD = 1.1000** waxay ka dhigan tahay **1 Euro = 1.10 US Dollars**.

## Xusuus

| Term                       | Macnaha                                               |
| -------------------------- | ----------------------------------------------------- |
| **Liquidity**              | Sida fudud ee pair loo iibsan karo ama loo iibin karo |
| **Volatility**             | Heerka uu qiimuhu u dhaqaaqayo                        |
| **Spread**                 | Farqiga Bid iyo Ask — kharashka entry                 |
| **Pip**                    | Cabbirka isbeddelka yar ee qiimaha                    |
| **Lot**                    | Cabbirka position-ka                                  |
| **Base / Quote**           | Currency 1aad / 2aad ee pair-ka                       |
| **Major / Minor / Exotic** | Noocyada pairs ee volume, USD, iyo emerging markets   |
